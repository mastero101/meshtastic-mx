¿Qué es Meshtastic?

Meshtastic es una plataforma de comunicación de código abierto que permite crear redes mesh descentralizadas usando dispositivos de bajo costo. Estas redes funcionan sin dependencia de infraestructura centralizada como torres celulares o internet.

Cada dispositivo actúa como un nodo en la red, retransmitiendo mensajes a otros dispositivos cercanos, creando una red de comunicación resiliente y autónoma.

Tecnología

Hardware

  • ESP32 / ESP8266 / nRF52840
  • LoRa Radio Modules
  • Dispositivos de bajo costo
  • Baterías de larga duración

Fabricantes

  • LilyGO – Placas populares con LoRa y pantalla
  • Heltec – Dispositivos compactos y robustos
  • Seeed Studio – Gran variedad de módulos LoRa
  • RAK Wireless – Módulos profesionales y kits

Software

  • Firmware Meshtastic
  • Aplicaciones móviles
  • APIs de desarrollo
  • Herramientas de configuración

Protocolos

  • LoRa (Long Range)
  • Mesh Networking
  • Encriptación AES
  • GPS integrado
