Paso a paso

Primeros pasos: configuración básica y conexión

¡Pon tu nodo en marcha en minutos!

¡Advertencia! No conectes el módulo sin tener la antena instalada. Esto puede dañar permanentemente el dispositivo.
  1. 1

    Flashear firmware

    Instala el sistema operativo de Meshtastic en tu dispositivo usando el flasheador web oficial.

    Abrir Web Flasher
  2. 2

    Instalar app

    Descarga la aplicación móvil para configurar y comunicarte con tu nodo.

    Android iOS
  3. 3

    Vincular nodo

    Enciende el Bluetooth de tu móvil y vincula el dispositivo desde la sección de configuración de la app.

  4. 4

    Configuración

    Ajusta la región (915MHz para México), el nombre de usuario y el nombre de tu nodo.

  5. 5

    Primer mensaje

    ¡Listo! Envía un mensaje al canal "LongFast" para confirmar que todo funciona correctamente.
